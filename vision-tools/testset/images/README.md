# testset/images

本目录**故意不包含图片**。

`../truth.json` 是对四张测试图的逐项真值标注（这是评分器 `vscore.py` 与
`eye.py --schema` 的基础）。真值里每条都带 `path` 字段，形如：

```
testset/images/ref-a.png
```

要让打分跑起来，把你自己的同名图片放进这个目录即可 —— 内容对不对得上由你决定，
真值本身描述的是**这几张图在各版本中被反复核对过的那些特征**。

四张图的用途：

| 名称 | 用途 |
| --- | --- |
| `synthetic.png` | 合成图，用于基线验证与机器可读文字（OCR 层） |
| `ref-a.png` / `ref-b.png` | 同一角色的两个版本，用于交叉比对与「两个版本 vs 读图不准」的区分 |
| `cute-01.png` | 风格化插画，用于测试非写实素材上的判断退化 |

不想准备图片也能用这套工具：`eye.py` 不带 `--schema` 时走的是自由问答与多模型比对，
完全不依赖真值集；只有打分（`--schema`）需要这些图。

## 为什么不做成「下载脚本」

真值集的价值在于**每一条都被人核过**。指向一个会自动下载的图片地址，等于把
「这张图到底是什么」交给网络状态的偶然性 —— 图换了、挂了、被替换成别的内容，
真值就变成一组无法复核的数字。宁可让使用者自己放图，也不要一个看起来能跑、
实际在拿错误基准打分的流水线。
