# 交接活档案（handoff-state）· **示例骨架**

> 这份是**唯一数据源**。改未结事项 / 结论 / 待办，只改这里；
> 然后跑 `handoff-check.ps1` 渲染出 `HANDOFF.md`。
>
> 规则：
>   1. 只有【跨会话需要接续】的内容才写进来 —— 机器能自动核对的事实（进程在不在、文件在不在）
>      **不要写**，那些由 `handoff-check.ps1` 每次实测。
>   2. 未结事项必须写「完成判据」，不然永远结不掉。
>   3. 办完就删（挪到 DONE 或直接删），别留成僵尸条目。
>   4. 每轮干活收尾时同步更新这里：**先改 state → 再 render → 再 check**。

## POINTERS

| 指针 | 路径 | 状态 |
| --- | --- | --- |
| 全局档案（规则 / 人格 / 台账） | `$env:DSH_HOME\AGENTS.md` | 常驻 |
| 工作区说明与文件清单 | `$env:DSH_WORKSPACE\AGENTS.md` | 常驻 |
| 交接活档案（本文件） | `$env:DSH_HOME\handoff\handoff-state.md` | 常驻 |
| 交接生成模板 | `$env:DSH_HOME\handoff\handoff-template.md` | 常驻 |
| 交接核对/生成脚本 | `$env:DSH_HOME\handoff\handoff-check.ps1` | 常驻 |

> 指针表里的每一行，脚本每次都会实测「文件还在不在」；死了会进警告栏。
