# dsh-handoff —— 给 AI 助手用的「跨会话交接」三件套

> 一个很小的机制，解决一个很大的问题：**AI 助手的上下文会被压缩、会丢，但文件不会。**
> 每次新会话开头，助手只说一句「读交接文件」，就能接着上次干活 —— 不用你重讲背景。

这套东西来自一个真实在用的 DSH（DeepSeek Harness）环境，已经跑了几百轮会话。**去掉了所有个人路径与私有内容，只留机制本身。**

---

## 它解决什么

| 症状 | 没有它的时候 | 有它的时候 |
| --- | --- | --- |
| 换一个会话 | 助手完全失忆，你要重讲一遍 | 读一次 HANDOFF 就能接续 |
| 「上次到底改完没有」 | 靠回忆，经常记错 | 脚本实测后写时间戳，**有凭据** |
| 三份文档各写一份事实 | 必然打架 | **单一数据源 + 机器渲染**，只有一份是真话 |
| 档案越写越大 | 写到超出注入预算，规则"写了但看不见" | 脚本能核对体积，超了就报 |

**设计原则一句话：能自动核对的一律交给脚本，人只维护一份不重复的活档案。**

---

## 三件套

| 角色 | 文件 | 谁维护 |
| --- | --- | --- |
| **数据源（唯一）** | `handoff-state.md` | 人（或助手）手写：未结 / 结论 / 挂起 / 指针表 |
| **渲染模板** | `handoff-template.md` | 基本不动 |
| **核对 + 渲染脚本** | `handoff-check.ps1` | 基本不动 |
| 交付物（**机器生成，别手改**） | `<workspace>\HANDOFF.md` | 脚本渲染 |

## 用法

```powershell
# 只核对不写文件（会话开场用）
pwsh -NoProfile -File .\handoff-check.ps1 -Check `
     -DshRoot "$env:USERPROFILE\.dsh" -Workspace "D:\my-project"

# 改了 state 之后：渲染出 HANDOFF.md
pwsh -NoProfile -File .\handoff-check.ps1 `
     -DshRoot "$env:USERPROFILE\.dsh" -Workspace "D:\my-project"
```

- 退出码 **0** = 全绿；**2** = 有 warning（脚本会逐条列出，也写进 HANDOFF 的「核对警告」栏）。
- **标准顺序**：改 `handoff-state.md` → render → `-Check` 复核 `CHECKED_AT`。顺序反了脚本会报「HANDOFF 比 state 旧」。

## `handoff-state.md` 怎么写

用注释块分段，脚本按标记切：

```markdown
<!-- STATE:STATUS -->
（当前状态：一段段"最后更新于…"的结论，可以很长）
<!-- /STATE:STATUS -->

<!-- STATE:PENDING -->
- 未结事项（每条写清「完成判据」）
<!-- /STATE:PENDING -->

<!-- STATE:DONE -->
- 已结案（办完就从 PENDING 挪过来，或直接删）
<!-- /STATE:DONE -->
```

**规则**：
1. 只有**跨会话需要接续**的内容才写进来；机器能自动核对的事实（进程在不在、文件在不在）**不要**写，交给脚本每次实测；
2. 未结事项必须写**完成判据**，不然永远结不掉；
3. 办完就删，别留僵尸条目。

## 模板里的 `{{#N}}` 是什么

渲染器用「位掩码」控制各段显示，**`N` 是全局 mask 的位**：

| 位 | 含义 |
| --- | --- |
| `1` | 有 warning |
| `4` | 皮肤被关（DSH 专属，可删） |
| `8` | boot 清单缺项 |
| `16` | 自检 FAIL |
| `32` | 漂移（某个档案比 HANDOFF 新） |
| `64` | 脚印过期 |
| `128` | 全绿 |

⚠️ **别拿 `{{#1}}` 当"正常态"用** —— 全绿时位 1 不成立，那一格会渲染成空白。正常态用 `{{#128}}`。

## 三个踩过的坑（都已在脚本里避开）

1. **脚本正文必须纯 ASCII**（如果你要把它挂进 Windows 计划任务）：计划任务用 PowerShell 5.1 跑，会把无 BOM 的 UTF-8 当 ANSI 读 → 中文变乱码 → 解析失败、退出码 1、**连日志都不写**。所有中文文案只放模板文件。
2. **日志别让 shell 重定向来写**（计划任务里 `*>` 不落盘）→ **脚本自己 `Add-Content` 写日志**。
3. **render 模式不许拿输出文件自己的旧 mtime 判漂移** —— 它马上要被覆盖，旧 mtime 只会把一句假的「本文件比 X 旧」永久写进新文件。**漂移检测只在 `-Check`（不写文件）时做。**

## 适配你自己的环境

1. 复制三个文件到你自己的目录；
2. 改 `handoff-check.ps1` 顶部的 `param` 默认值（`$DshRoot` / `$Workspace` / `$LogPath`）；
3. 把你**想每次实测的检查项**写进 `Get-*` 那几段（脚本里检查了：人格插件脚印、boot 清单、计划任务状态、关键文件时间戳、指针表存活）；
4. 不需要的段直接删 —— 它是你的，不是我的。

**依赖**：Windows PowerShell 5.1+ / PowerShell 7+，无第三方模块。
