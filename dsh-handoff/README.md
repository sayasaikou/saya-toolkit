# dsh-handoff：跨会话交接机制

AI 助手的会话上下文会被压缩或重置，而文件系统的状态是持久的。本组件用于在会话之间传递工作状态，使新会话无需重新交代背景即可继续此前的工作。

本机制已在长期运行的 DSH（DeepSeek Harness）环境中持续使用，本仓库版本已移除全部环境相关信息，仅保留机制本身。

## 解决的问题

| 问题 | 不使用本机制 | 使用本机制 |
| --- | --- | --- |
| 会话切换 | 助手无此前上下文，需重新交代 | 读取交接文档即可继续 |
| 改动是否完成 | 依赖回忆，易出错 | 脚本实测后写入时间戳，可追溯 |
| 多份文档记录同一事实 | 内容冲突 | 单一数据源，由脚本统一渲染 |
| 档案持续增长 | 超出注入预算，规则实际未生效 | 脚本核对体积并给出告警 |

设计原则：**可自动核对的项交由脚本执行，人工只维护一份不重复的状态文件。**

## 组成

| 角色 | 文件 | 维护方式 |
| --- | --- | --- |
| 数据源（唯一） | `handoff-state.md` | 人工维护：未决项、结论、挂起项、引用指针 |
| 渲染模板 | `handoff-template.md` | 基本固定 |
| 核对与渲染脚本 | `handoff-check.ps1` | 基本固定 |
| 交付物（机器生成） | `<workspace>\HANDOFF.md` | 由脚本渲染，不应手工修改 |

## 使用方法

```powershell
# 仅核对，不写入文件（会话开始时使用）
pwsh -NoProfile -File .\handoff-check.ps1 -Check `
     -DshRoot "$env:USERPROFILE\.dsh" -Workspace "D:\my-project"

# 修改状态文件后：渲染生成 HANDOFF.md
pwsh -NoProfile -File .\handoff-check.ps1 `
     -DshRoot "$env:USERPROFILE\.dsh" -Workspace "D:\my-project"
```

退出码：`0` 表示无异常；`2` 表示存在告警（脚本会逐条列出，并写入交接文档的核对告警栏）。

标准操作顺序：修改 `handoff-state.md` → 渲染 → 使用 `-Check` 复核核对时间戳。顺序颠倒时脚本会报告交接文档早于状态文件。

## 状态文件格式

状态文件通过注释块分段，脚本按标记读取：

```markdown
<!-- STATE:STATUS -->
（当前状态：按条目记录结论与更新时间）
<!-- /STATE:STATUS -->

<!-- STATE:PENDING -->
- 未决事项（每项须写明完成判据）
<!-- /STATE:PENDING -->

<!-- STATE:DONE -->
- 已结案事项
<!-- /STATE:DONE -->
```

编写规则：

1. 仅记录跨会话需要接续的内容。可由脚本自动核对的事实（进程状态、文件是否存在）不应写入，由脚本每次实测。
2. 未决事项必须写明完成判据，否则无法结案。
3. 事项办结后应从 PENDING 移除或移入 DONE，避免无效条目累积。

## 模板中的 `{{#N}}` 标记

渲染器使用位掩码控制各段落显示，`N` 为全局状态掩码的位：

| 位 | 含义 |
| --- | --- |
| `1` | 存在告警 |
| `4` | 皮肤开关被关闭（DSH 环境专用，可按需删除） |
| `8` | 启动清单存在缺失项 |
| `16` | 自检失败 |
| `32` | 状态漂移（某档案比交接文档更新） |
| `64` | 加载脚印过期 |
| `128` | 全部正常 |

正常状态应使用 `{{#128}}`。位 `1` 在正常状态下不成立，对应段落会渲染为空。

## 已规避的实现问题

1. **脚本正文必须为纯 ASCII**（用于 Windows 计划任务时）。计划任务以 Windows PowerShell 5.1 执行，会将无 BOM 的 UTF-8 文件按 ANSI 解析，导致中文注释乱码、脚本解析失败并返回退出码 1，且不会写出日志。所有中文文案应放在模板文件中。
2. **日志不应由 shell 重定向写入**。在计划任务环境中 `*>` 无法落盘，日志应由脚本自身追加写入。
3. **渲染模式不应以输出文件自身的修改时间判定漂移**。该文件即将被覆盖，旧时间戳会导致错误的漂移记录被写入新文件。漂移检测应仅在 `-Check` 模式（不写入文件）中执行。

## 环境适配

1. 复制三个文件至目标目录。
2. 修改 `handoff-check.ps1` 顶部的参数默认值与配置块（`$MonitoredTasks`、`$BootExpect`、`$PersonaPlugin`、`$MemeGlob`）。
3. 按需在核对函数中增删检查项。

依赖：Windows PowerShell 5.1 及以上，或 PowerShell 7 及以上。无第三方模块依赖。
