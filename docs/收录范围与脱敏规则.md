# 收录范围与脱敏规则

本文件说明本仓库的收录标准，以及文档在公开前所需的最小化处理。

## 一、收录标准

内容需同时满足以下条件方可收录：

1. **已在实际环境中验证可用**，而非演示性质或未完成的实验代码；
2. **具备可迁移性**，不依赖特定账号、特定设备或不可公开的内部系统；
3. **附带可复核信息**：实测数据、验证方式、失败方案记录、回滚方案至少具备其一；
4. **经脱敏处理后不含环境相关信息**（见第二节）。

## 二、脱敏规则

公开前须完成以下处理，并逐项复核：

| 类别 | 处理方式 |
| --- | --- |
| 用户名、账号名 | 移除，或替换为占位符 |
| 绝对路径 | 替换为环境变量（`$env:DSH_HOME`、`$env:DSH_WORKSPACE`、`$env:DSH_AI` 等）或占位符 |
| 设备标识 | 移除机器名、序列号、MAC 地址；机型改为描述性说明，保留容量、频率、温度、功耗等可复现的量化参数 |
| 计划任务名、插件名等部署细节 | 改为可配置项，或以通用名占位 |
| 凭据（令牌、密钥、口令） | 不收录。相关逻辑仅保留机制说明 |
| 个人事务信息（学业、作息、社交账号等） | 不收录 |
| 日志与配置原文 | 仅保留结论性内容与必要的片段，不收录完整原始文件 |

复核方式：完成处理后对全部文件执行关键词扫描，确认无残留；对脚本执行语法检查，并在**不含原环境的空目录中运行**，确认不产生由于环境缺失导致的错误行为（如误报警告）。

## 三、不收录的内容

以下内容即使具备技术价值，也不纳入本仓库：

- 用户档案、设备台账等个人环境文档的正文（仅保留结构说明与示例骨架）；
- 会话记录、对话语料；
- 涉及第三方知识产权且许可状态未确认的素材与交付物；
- 依赖特定账号或私有服务才能运行的内容。

## 四、维护方式

新增内容按以下流程纳入：

1. 完成脱敏处理；
2. 执行关键词扫描与语法检查；
3. 在空目录中运行验证；
4. 补充文档说明（用途、使用方法、已知限制）；
5. 提交并更新本文件的相关说明。

**闸门清单（可执行，缺一项不算通过）**

| # | 闸门 | 判据 |
| --- | --- | --- |
| 1 | 关键词扫描 | 全仓搜用户名、机器名、私有角色名、本机绝对路径 —— **0 命中** |
| 2 | 编码与换行 | 全部 UTF-8 无 BOM；`.ps1`/`.py`/`.json` 为 LF（CR 计数 = 0） |
| 3 | 脚本语法 | PowerShell 用 `Parser::ParseFile` **两种引擎各跑一次**（7 与 5.1）；Python 用 `py_compile` |
| 4 | 空环境运行 | 在空目录 / 不存在的输入路径下运行，确认**不崩溃、不误报**（缺东西应报 `n/a` 或跳过，不是告警） |
| 5 | 计划任务脚本纯 ASCII | 面向计划任务的 `.ps1` 非 ASCII 字节数必须为 **0** |
| 6 | 危险操作需显式参数 | 涉及删除的脚本**不得有本机默认路径**：根目录必须显式传入 |

**文档的证据分级**：凡写结论，标注它属于哪一档 —— 「**实测**」（有可复核输出）、「**现场记录**」（真实发生过但触发条件未完全复现）、「**机制推断**」（由已知机制推出，未直接验证）。三档不混写；标注为推断的内容，不得在后续引用中被升级为确定结论。

## 五、已知限制

- 文档中的实测数据均来自特定测试环境，硬件配置不同时结论可能不适用，相关环境信息在各文档中描述；
- 部分组件依赖 Windows 平台特性（计划任务、共享内存、PE 子系统行为、硬链接语义），在其它平台不可用；
- 路径一律通过环境变量或参数配置。**涉及删除的脚本不给默认根目录**（默认值写错就会删错树），首次使用需显式传参。
