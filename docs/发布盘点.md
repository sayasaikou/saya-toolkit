## 三、必须留在本地（公开价值低 或 含隐私）

| 资产 | 原因 |
| --- | --- |
| `AGENTS.md`（全局 / 工作区） | 含**真实个人档案**（学校、专业、技能、健康与作息、在校安排）与设备序列级信息 |
| `handoff-state.md` 的真实内容 | 209 KB 的机器与个人台账，**泄露面极大**；只公开结构与示例 |
| 人格注入规格 / 风格配方 / 关系记忆 / 会话语料 | 高度个人化，且语料是真实对话记录 —— **未经本人逐句审阅不公开** |
| 凭据类（`.credentials.yaml` / `settings.yaml` / `*.log` / 会话日志 / 附件） | 硬红线：**永不入任何仓库**（私有仓也已拦截） |
| 学业 / 战队材料（报名表、面试稿、PPT） | 含真实经历与个人信息 |
| 出图交付物（生图-过筛、角色表 xlsx） | 含第三方 IP 角色图，**版权与素材许可未核**，先不公开 |
| 大赛/工程交付物（MV 工程、双烤原始 CSV） | 体积大 + 含机器实测数据，按需再定 |

## 四、复刻这套东西的顺序（建议）

1. **先抄 `run-hidden`**（最小、收益最大：任何用计划任务的人都会遇到闪窗）；
2. **再抄交接机制**（收益随时间增长：会话越多越值）；
3. 然后按需抄监控 / 出图 / 渲染；
4. **别一次搬全家**：先跑通一个，确认能用，再搬下一个。

## 五、已知限制（诚实记）

- 所有"实测数据"都来自**一台机器**（MSI Vector 16 HX AI A2XWIG / Ultra 9 275HX / RTX 5080 Laptop 16G），换机不复现属正常；
- 计划任务、MAHM、`run-hidden` 都是 **Windows 专属**，Linux/macOS 不可用；
- 部分脚本仍含本机默认路径（环境变量兜底），跑不起来先看路径；
- **本机网络对 `github.com` 主站被 SNI 阻断**：`git` 走 `ssh.github.com:443` 能通（实测 4.57 MB/s），
  但 **OAuth 设备码流程（`gh auth refresh`）不通** —— 想加 token scope 需要能上主站的网络或 `gh` 的浏览器登录。
